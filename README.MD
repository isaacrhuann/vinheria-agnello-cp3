### Descrição do Projeto
Este sistema foi desenvolvido para o CP 03 de Web Development. Ele simula o controle interno de estoque de uma vinícola (Vinharia Agnello). O sistema não possui interface de usuário complexa nem formulários, operando inteiramente através do console do navegador e de alertas.

### Tecnologias e Conceitos Aplicados
- Manipulação de **Arrays de Objetos**.
- Criação e reutilização de **Funções**.
- Utilização de **Funções de Alta Ordem** no JavaScript:
  - `forEach()` para listagem de dados.
  - `filter()` para identificar vinhos com estoque abaixo de 5.
  - `map()` para transformar os nomes dos vinhos em letras maiúsculas.
  - `reduce()` para calcular o número total de garrafas no estoque da vinícola.
